# PowerShell security features

- Execution policy helps protect against accidental script execution; it is not a security boundary. It is enforced only on Windows.
- PowerShell security also involves mechanisms such as logging, AMSI, language modes, and application control. Treat the overview below as an introduction, not as a complete security configuration guide.
- Review and trust downloaded scripts and modules before running them. Keep credentials out of source files, logs, and transcripts.
